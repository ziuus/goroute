# AGENTS.md — Agent Operations & Working Agreement

GoRoute is an ultra-low-latency, single-binary AI gateway and multi-account router (< 5 MB RAM) with Rust SIMD acceleration.

---

## 1. Quick Commands

```bash
# Build core daemon binary
go build -o bin/goroute ./cmd/goroute

# Run full test suite with race detector
go test -v -race ./...

# Run memory & concurrency benchmark verification
go test -v -run=TestMemoryAndConcurrency ./tests

# Recompile frontend dashboard (when modifying web-ui/)
cd web-ui && bun run export-to-goroute && cd .. && go build -o bin/goroute ./cmd/goroute

# Compile optional Rust SIMD acceleration cdylib
cd crates/goroute-fast && cargo build --release && cd ../..
```

## 2. Key Repository Structure

```
goroute/
├── cmd/goroute/         # Cobra CLI entrypoints (serve, auth, setup, run, sync)
├── pkg/proxy/           # HTTP server, Chi mux, /v1/chat, /v1/messages, auth & streaming
├── pkg/router/          # Virtual combos, fallback cascades, EWMA latency selection
├── pkg/providers/       # Upstream adapters (antigravity, kiro, codex, copilot, openai)
├── pkg/tokens/          # Anthropic count_tokens API & proactive background refresh loop
├── pkg/storage/         # SQLite WAL persistence (~/.goroute/goroute.db)
├── pkg/fast/            # Purego dynamic linking bridge to Rust cdylib
├── crates/goroute-fast/ # Rust SIMD resolver & prompt tokenizer
├── web/dist/            # Embedded static HTML/CSS/JS (embedded via //go:embed)
├── web-ui/              # Next.js 15 source code for the dashboard
└── tests/               # Concurrency and sub-5MB memory footprint regression suites
```

## 3. Conventions Agents Commonly Get Wrong

1. **Zero CGO**: GoRoute runs with `CGO_ENABLED=0` across Linux, macOS, and Windows. Dynamic library loading uses `ebitengine/purego` at runtime, not CGO.
2. **Never Edit `web/dist/*` Directly**: Static assets in `web/dist/` are generated. Always edit source in `web-ui/app/` and run `bun run export-to-goroute` (or `npm run export-to-goroute`).
3. **Loopback CLI Exemption**: Requests from `127.0.0.1` and `::1` carry trusted agent context (`isLoopback`) to allow seamless local agent handshakes without artificial auth rejections.
4. **Stripping Model Route Prefixes**: When proxying to upstream Google Cloud Code (Antigravity), strip client-side routing namespaces (e.g. `antigravity/` or `claude/`) before invoking Google endpoints.
5. **SSRF Link-Local Protection**: Upstream provider URLs must validate against AWS/GCP link-local metadata endpoints (`169.254.169.254`, `100.100.100.200`, `metadata.google.internal`) using `ValidateBaseURL`.
6. **No Mock Telemetry**: Never hardcode fake token counts, fake worker lists, or simulated countdowns. All dashboard APIs read empirical state from runtime engines.

## 4. Do Not Modify

- `go.sum` (use `go mod tidy` instead of manual edits)
- `web/dist/*` (generated by Next.js static export)
- `crates/**/target/` (Cargo build artifacts)
- `~/.goroute/goroute.db*` (managed at runtime by SQLite WAL engine)
